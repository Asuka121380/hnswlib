## Execution state

The local machine contains a shadow-enabled `v0_search_runner`, but it does not
contain the full GIST1M `dataset.json`, HNSW index, or `.v0meta` sidecar. The
archived July 29 metadata points to the cluster copies under
`$HOME/IndividualProject`. Consequently, the real 100/1000-query runs have not
been fabricated or replaced with toy results; they must be submitted on the
data-bearing cluster.

A non-interactive connectivity probe to `cluster1.comp.anu.edu.au` timed out on
2026-08-03. The project environment guide notes that ANU GlobalProtect VPN may
be required. Connect the VPN before submitting the job.

After syncing the implementation to the cluster repository, run:

```bash
python3 scripts/v0/shadow_diagnostic/test_analyze_shadow_diagnostic.py
sbatch scripts/v0/shadow_diagnostic/run_minimal_shadow_diagnostic.slurm
```

The job stops before Stage B if any Stage A gate fails. On success, its final
results are written under
`$HOME/IndividualProject/results/v0_shadow_diagnostic/gist1m/20260803-minimal`.
